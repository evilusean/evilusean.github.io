How to use

What this is

A local-first timeline app. Events live in your browser. Google Sheets is an optional sync backend you can edit like a normal spreadsheet. Everything works offline.

Dates

Use YYYY-MM-DD (ISO 8601). BCE years use a leading minus: -0753-04-21. Only the start date is required — leave end date blank for point events.

Built-in timelines

Pick from the dropdown (top left): Western canon, empires, financial crises, human-rights documents. Your edits are saved locally per timeline. ＋ New creates a blank one.

Adding & editing events

Click ＋ (bottom right) to add. Click any marker to open the detail panel — then hit Edit. Hover a marker for the quick-action card. Fields include:

  • Parent event — nest this under another event (unlimited depth: Empire → War → Battle). Events with children show a small amber ring under their emoji.
  • People — space-separated @handles linking to People sheet records (e.g. @julius_caesar).
  • Location — free text, shown in the detail panel.
  • Tags — #hashtags. Shared tags draw connection lines when Connections is on.
  • Importance 1–10 — scales the emoji marker size.

Drill-down

Click 🔍 Drill in on any event (detail panel or hover card) to filter the timeline to that event and all its descendants. A breadcrumb bar appears — click any crumb to navigate up, or hit ✕ All events to clear. Clicking “under ParentName” in the detail panel drills into the parent. Escape also clears drill.

Views & layout

  • Timeline (default) — horizontal axis, wraps into stacked rows. Use Layout and Rows controls to switch between wrap and single strip, and to fix the row count.
  • 🌀 Spiral — Archimedean spiral, oldest outermost, newest at centre. Scroll wheel zooms toward the pointer. ⊙ resets zoom and pan.
  • Slice — pick Decade or Century, then use ‹ › to step through time windows. The chip bar shows all windows; click any chip to jump directly.
  • From / To — manual date-range filter in the controls bar.

Slideshow

Click ▶ Slideshow. Events play in date order: the name fades in first, then dates, then description and tags. Space pauses (and fast-forwards to full detail), arrows skip, Esc stops.

Google Sheets

  1. Sign in with Google.
  2. Click 🔗 Connect Sheet — create a new spreadsheet or paste an existing URL/ID.
  3. 📊 Events Sheet / 👤 People Sheet open those tabs in Google Sheets.
  4. ⬇️ Sync pulls rows down; ⬆️ Push writes the current timeline up.

Import / Export

💾 Export downloads the current timeline as CSV. 📂 Import loads a CSV — or drag a .csv file onto the page. Columns match the full schema including parent_id, people, and location.
